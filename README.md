## Marketing_sales_analysis
Анализ и прогнозирование выручки на маркетинговом датасете

## Данные

- **Источник:** https://www.kaggle.com/datasets/abdelfattahibrahim/marketing-sales-dataset/data
- **Размер:** 60000 строк, 23 колонки
- **Целевая переменная:** `sales_revenue_usd` (выручка в долларах)

## Задачи

| № | Задача |
|---|--------|
| 1 | Разведочный анализ данных (EDA) |
| 2 | Проверка статистических гипотез |
| 3 | Построение модели предсказания выручки |
| 4 | Анализ важности признаков |
