## Marketing_sales_analysis
Анализ и прогнозирование выручки на маркетинговом датасете

## Данные

- **Источник:** https://www.kaggle.com/datasets/abdelfattahibrahim/marketing-sales-dataset/data
- **Размер:** 60000 строк, 23 колонки
- **Целевая переменная:** `sales_revenue_usd` (выручка в долларах)

## Задачи

| № | Задача |
|---|--------|
| 1 | Разведочный анализ данных (EDA) |
| 2 | Проверка статистических гипотез |
| 3 | Построение модели предсказания выручки |
| 4 | Анализ важности признаков |

## Используемые библиотеки

- pandas, numpy — обработка данных
- matplotlib, seaborn — визуализация
- scipy — статистические тесты
- scikit-learn — модели машинного обучения

## Ключевые выводы EDA

- **VIP и Corporate** дают средний чек в 2-2.5 раза выше, чем Regular и New
- **Скидки выше 20%** снижают выручку на 5.5%
- **Q4** — самый прибыльный квартал во всех регионах
- **Категория товара** влияет на выручку (лидеры — Electronics и Home Appliances)
- **Маркетинговый бюджет** коррелирует с выручкой (0.73), но это обратная причинность: крупные сделки получают больше бюджета

## Проверенные гипотезы

| Гипотеза | Результат |
|----------|-----------|
| Высокие затраты на рекламу приводят к увеличению выручки | Отвергается |
| Увеличение размера скидки приводит к снижению выручки | Подтверждается |
| Чем больше у клиента предыдущих покупок, тем выше его средний чек| Отвергается |
| Q4 приносит максимальную выручку во всех регионах | Подтверждается |

## Модель машинного обучения

**Модель:** Random Forest Regressor

| Метрика | Значение |
|---------|----------|
| MAE | 719 USD |
| R2 | 0.94 |

Модель объясняет 94% дисперсии выручки. Средняя ошибка предсказания — 12% от среднего чека.

## Самые важные признаки для предсказания

1. marketing_budget_usd
2. customer_segment_Regular
3. customer_segment_New
4. product_category_Electronics
5. season_Q4

## 9. Ограничения

- Модель плохо предсказывает аномально крупные сделки (>50,000 USD) из-за сильного дисбаланса классов (0.2% данных)
